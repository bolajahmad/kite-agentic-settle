## ABI Summaries

### IdentityRegistry

```
registerAgent(name, category, uri) → agentId
getAgent(agentId) → (owner, wallet, uri, createdAt)
resolveByWallet(wallet) → agentId
```

### KiteAAWallet

```
setSession(key, budget, maxPerCall, validUntil, allowedRecipients)
revokeSession(key)
execute(target, value, calldata)
isSessionValid(key) → bool
```

### PaymentChannel

```
openChannel(provider, token, deposit, maxSpend, maxPerCall, maxDuration)
activateChannel(channelId)
updateState(channelId, receipt, signature)
initiateSettlement(channelId)
finalizeChannel(channelId)
getChannel(channelId) → ChannelInfo
```

### AttestationRegistry

```
setMerkleRoot(root, uri, nonce) → recordId
verifyRecord(recordId, leaf, proof) → bool
getRecord(recordId) → (agent, root, uri, timestamp)
```

## Full ABIs

Full ABI JSON files are in `contracts/artifacts/contracts/`:

- `IdentityRegistry.sol/IdentityRegistry.json`
- `KiteAAWallet.sol/KiteAAWallet.json`
- `PaymentChannel.sol/PaymentChannel.json`
- `AttestationRegistry.sol/AttestationRegistry.json`

The SDK imports these automatically — you don't need to reference them directly unless you're calling the contracts with viem/ethers directly.
