# Demo 3: Batch Channel Flow

This demo shows how to open a payment channel, make multiple calls with off-chain receipts, and settle at the end — paying only 2 on-chain transactions instead of N.

**Source:** `mcp-sdk/examples/03-batch-channel-flow.ts`

## What It Does

1. Opens a batch channel with a 5 USDT deposit
2. Makes 5 API calls — all off-chain, no gas per call
3. Settles the channel with a single transaction
4. Reports the gas savings vs per-call mode

## Running It

```bash
cd mcp-sdk
npm run demo 3
```

## Code Walkthrough

```typescript
const client = await KiteSettleClient.create({ credential, agentId: "1" });

// Open channel — 1 on-chain tx
const channel = await client.openChannel({
  provider: PROVIDER_ADDRESS,
  token: DM_USDT,
  deposit: parseUnits("5.0", 18),
  maxSpend: parseUnits("4.5", 18),
  maxPerCall: parseUnits("0.5", 18),
  maxDuration: 3600,
});

// 5 calls — all off-chain (no gas)
for (let i = 0; i < 5; i++) {
  const response = await client.callOnChannel(
    channel.channelId,
    "http://localhost:4000/api/data/protocol-report"
  );
  console.log(await response.json());
}

// Settle — 1 on-chain tx
await client.initiateSettlement(channel.channelId);
```

## Gas Comparison

| Mode | 5 Calls | 50 Calls | 100 Calls |
|---|---|---|---|
| Per-call (x402) | 5 txs | 50 txs | 100 txs |
| Batch channel | 2 txs | 2 txs | 2 txs |
