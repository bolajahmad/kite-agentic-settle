# Demo 1: Per-Call Payment

This demo shows the simplest Kite payment model: each API call is paid individually using x402.

**Source:** `mcp-sdk/examples/01-percall-payment.ts`

## What It Does

1. Creates a `KiteSettleClient` with an existing agent and session key
2. Calls a price-gated API endpoint
3. Receives a 402 challenge with price and provider address
4. Signs and submits a payment
5. Gets the API response

No channel is opened. Each call is fully self-contained.

## Running It

```bash
cd mcp-sdk
npm run demo 1
```

Or with the CLI:

```bash
npx kite simulate --demo 1
```

## Code Walkthrough

```typescript
import { KiteSettleClient, KITE_TESTNET } from "@kite-agentic-pay/sdk";

const client = await KiteSettleClient.create({
  credential: process.env.CREDENTIAL,
  agentId: "1",
});

// fetchWithPayment is a drop-in replacement for fetch
const response = await client.fetchWithPayment(
  "http://localhost:4000/api/data/protocol-report",
  { method: "GET" },
  { paymentMode: "perCall" }
);

const data = await response.json();
console.log(data);
```

## Key Points

- **Per-call payments** are on-chain for every call. Gas costs apply each time.
- Suitable for **low-frequency, high-value** API calls
- For frequent calls, use [Batch Channel →](./batch-flow) to amortize gas costs
