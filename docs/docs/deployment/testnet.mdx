## Getting Testnet ETH

Use the Kite AI faucet or bridge ETH from another testnet. You need ETH for:
- Bundler operations (gas for AA wallet transactions)
- Direct EOA transactions (session management)

## Getting DmUSDT

DmUSDT is the demo stable token. Get it by:

```bash
npx kite fund 10
```

This calls the DmUSDT faucet function directly. You get 10 DmUSDT deposited into your AA wallet.

## Deploy Your Backend to Testnet

Your backend connects to testnet by default. Set:

```env
CHAIN_ID=2368
RPC_URL=https://rpc-testnet.gokite.ai
BUNDLER_URL=https://bundler-service.staging.gokite.ai/rpc/
```

Then deploy using any Node.js hosting platform (see [Deploy a Provider →](../guides/deploy-provider)).

## Verify On-Chain

After onboarding:

```bash
npx kite whoami
```

Expected output includes your agent ID, AA wallet address, and session key. You can verify the agent is registered by checking the IdentityRegistry:

```bash
npx hardhat run --network kite_testnet scripts/verify-agent.js
```

Or query the subgraph:

```graphql
query {
  agentRegistered(id: "1") {
    owner
    agentWallet
    uri
  }
}
```
