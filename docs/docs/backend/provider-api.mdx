# Provider API Reference

## Request Headers (Provider Receives)

### x402 Mode

| Header | Description |
|---|---|
| `X-PAYMENT` | Base64-encoded EIP-712 signed payment struct |
| `X-PAYMENT-VERSION` | Protocol version (currently `1`) |

### Channel Mode

| Header | Description |
|---|---|
| `X-Channel-Id` | Channel ID (bytes32 hex) |
| `X-Channel-Receipt` | Base64-encoded signed receipt struct |

## x402 Middleware

```typescript
import { x402Middleware } from "@/middlewares/x402";

router.get(
  "/api/data/report",
  x402Middleware({
    price: parseUnits("0.40", 18),
    token: DM_USDT_TOKEN,
    providerAddress: process.env.PROVIDER_ADDRESS,
  }),
  reportHandler
);
```

The middleware:
1. Returns a `402 Payment Required` response on first request (no payment header)
2. Validates the EIP-712 payment struct from `X-PAYMENT` on retry
3. Verifies the session key is active on-chain
4. Checks that the amount matches the required price
5. Passes to the route handler if valid

## Channel Middleware

```typescript
import { channelMiddleware } from "@/middlewares/channel";

router.get(
  "/api/stream/intelligence",
  channelMiddleware({
    pricePerCall: parseUnits("0.10", 18),
    providerAddress: process.env.PROVIDER_ADDRESS,
  }),
  streamHandler
);
```

The middleware:
1. Reads `X-Channel-Id` and `X-Channel-Receipt` headers
2. Verifies the receipt signature against the channel's session key
3. Checks sequence number is strictly increasing
4. Updates the local receipt store
5. Passes to the route handler

## Payment Validation Utilities

```typescript
import {
  verifyX402Payment,
  verifyChannelReceipt,
  validateSessionKey
} from "@kite-agentic-pay/sdk";

// Validate an x402 payment header
const result = await verifyX402Payment(req.headers["x-payment"], {
  expectedPrice: parseUnits("0.40", 18),
  expectedToken: DM_USDT_TOKEN,
  expectedProvider: PROVIDER_ADDRESS,
  rpcUrl: KITE_TESTNET.rpcUrl,
});

// Validate a channel receipt
const receiptResult = await verifyChannelReceipt(
  req.headers["x-channel-receipt"],
  req.headers["x-channel-id"],
  { rpcUrl: KITE_TESTNET.rpcUrl }
);
```
